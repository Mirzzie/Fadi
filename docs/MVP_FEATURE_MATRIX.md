## MVP Acceptance Definition

MVP is complete only when:

- A user can complete onboarding.
- A resume can be uploaded and parsed.
- LinkedIn data can be pasted/imported enough to improve the profile.
- Career analysis generates useful, editable insights.
- Jobs can be discovered and recommended.
- The dashboard makes the next action obvious.
- The AI assistant can answer grounded career questions.
- Learning recommendations exist.
- Applications can be tracked manually.

## Deferred Feature Rule

Any feature that does not directly help the first 100 users complete onboarding, understand their career state, find jobs, or track applications is deferred.
