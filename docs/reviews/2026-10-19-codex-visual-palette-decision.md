# Visual palette decision · Pipecat signal family

**Decision:** retire Fadi's teal/cyan identity and use a Pipecat-inspired signal palette.

The three named references were checked in their current public sites on 19 October 2026:

- Pipecat uses zinc neutrals with a coherent indigo family (`#4f39f6`, `#7d87ff`, `#584dfc`) and
  restrained yellow (`#edd83d`) for announcements.
- Paperclip uses a broad multi-colour operational palette: green, pink, amber, yellow, violet and
  teal. It is useful for dense agent administration but too diffuse for Fadi's calmer journey.
- UniMad uses a conventional strong blue (`#346de0`) on black/white. It is clear, but less
  distinctive and more marketing-led.

Pipecat wins because it is the primary visual reference already, avoids the retired teal/cyan
identity, works in both light and dark modes, and lets semantic success/warning/error colours remain
meaningful.

## Applied globally

- primary and focus: indigo;
- active surface: pale indigo;
- depth and Fadi presence: violet;
- attention: yellow, used sparingly;
- canvas, cards and typography: zinc/neutral;
- Fadi mark, core, navigation, job-search activity and the modern résumé template now use the same
  family.

This borrows a palette relationship, not Pipecat's name, logo, illustrations or layout.
