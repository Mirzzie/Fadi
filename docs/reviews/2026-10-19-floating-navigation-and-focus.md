## Navigation decision

The four destinations now live in a compact floating bottom dock on every ordinary screen. It does
not reserve horizontal layout space. Labels remain visible from 420px upward; icons retain semantic
link names below that width.

Project workspaces and work simulations are focus routes. They suppress:

- the bottom dock;
- destination sub-navigation;
- the floating Fadi launcher.

The menu bar remains as the escape hatch and owner of global approvals/account state. Fadi remains
reachable from its state in that bar.

## Apply / Prepare audit

The state is useful: it changes Today prioritisation and Fadi's voice guidance. The permanent global
switch was not useful enough to occupy every page. It now appears only on Today, where the choice is
made and its effect is visible, with user-language labels:

- Find work (`apply` internally)
- Build skills (`prepare` internally)

The same cookie, server action, context, and server-rendered behavior remain authoritative.

## Surface delta

- Removed the 200px desktop layout reservation entirely.
- Restored a compact floating dock with four destinations.
- Restored the brand to the shallow top bar.
- Added focused layout behavior to both lab projects and Practice simulations.
- Moved career phase selection from global chrome to the Today introduction.
