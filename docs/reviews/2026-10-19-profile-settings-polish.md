# Profile and Settings polish — 19 October 2026

## Reference basis

Uses the REA-observed Paperclip/Pipecat system recorded in the shared design audit: neutral paired
themes, Inter Tight display hierarchy, monospace utility labels, thin rules, and no decorative
gradient where structure is sufficient.

## Surface delta

- Removed duplicated gradient text, blurred color orbs, glowing icon tiles, and boxed page heroes.
- Gave both routes consistent editorial titles and supporting copy.
- Corrected Settings' page title: it previously presented the entire settings route as only
  “AI provider” even though it also contains tools, accounts, preparation, Notion, and MCP access.
- Added consistent bottom clearance for the floating dock.
- Retained the narrow form measure for readability; reclaiming space does not mean stretching form
  controls across unusably long lines.

## State and actions

All forms, credentials, connections, sessions, and actions retain their existing repositories and
server-action owners. No new page-level primary action was introduced; each settings section owns
its own save/connect action.
