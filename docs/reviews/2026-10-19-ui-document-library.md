# Document library surface delta — 19 October 2026

## Scope

Presentation-only migration of the shared document library from a rounded preview-card gallery to
a compact editorial working list.

## Authoritative state

Document content, kind, update time, creation, import, and deletion remain owned by the existing
document repository and server actions. The list renders those values without deriving new status.

## Primary action

**New resume** is the default primary action. Other document kinds and CV import remain adjacent
secondary actions. Opening an existing document remains its row action; deletion stays a concealed
destructive control revealed by hover or focus.

## Visible change

- Removed the aurora decoration, gradient heading, pill label, faux-paper previews, and card grid.
- Added an editorial page introduction and a thin-ruled, dense document library.
- Retained short content previews and updated dates as supporting metadata.

## Out of scope

The document editor, history, print layout, and truth-check behavior are unchanged in this slice.
